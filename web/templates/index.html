Quick Start

Add this repository to Helm:

helm repo add pertisk http://localhost:7080
helm repo update

Upload a chart:

curl -X POST http://localhost:7080/api/charts \
  -F "chart=@mychart-1.0.0.tgz"

Browse charts:

Visit /charts
